# Data Visualisation in Data Science - Project Scoresheet 1: Designs
**Course Code:** G0R72A
**Version:** 20240304

## Overview of Design Space Concepts
The project evaluates how a student navigates the design space. The process is categorized into three nested phases:
1. **You Know:** The baseline of existing knowledge.
2. **You Explore (Diverge + Emerge):** Broadening the scope of possibilities and identifying patterns.
3. **You Use (Converge):** Selecting and refining the final design path.

---

## 1. Design Space Exploration
*Is the design space explored?*

| Score | Level | Description |
| :--- | :--- | :--- |
| **+0** | **Poor** | The explored design space is very limited (e.g., designs are too similar). |
| **+1** | **Sufficient** | Different charts were explored, but they are all standard (e.g., basic R plots) and used in a standard way. |
| **+2** | **Good** | Novel and interesting designs (beyond basic bar/scatter plots) were explored. |

> **IMPORTANT:** Different charts may look visually similar but be semantically different. Conversely, familiar designs used in unconventional ways (e.g., a node-link network used to represent geographical locations) count as exploration. Take semantic usage into account.

---

## 2. Well-Annotated Designs
*Are the designs clearly labeled and explained?*

| Score | Level | Description |
| :--- | :--- | :--- |
| **+0** | **Poor** | Annotations are missing or don't help understanding. Key elements are unlabelled. |
| **+1** | **Sufficient** | Annotations are present but minimal or generic. Modest utility for the reader. |
| **+2** | **Good** | Clearly labels key elements and provides context for interpretation. Includes explanations of visual encoding and design rationale. |

---

## 3. Meaningful Reworking
*Are the original designs iterated upon?*

| Score | Level | Description |
| :--- | :--- | :--- |
| **+0** | **Poor** | No "emerge" or "converge" phases were performed. |
| **+1** | **Sufficient** | A single cycle of **diverge-emerge-converge** was performed. |
| **+2** | **Good** | Multiple iterations of visual exploration were performed. Ideas from previous rounds were evolved into the next, with descriptions of their utility for the research question. |

---

## 4. Explanation of Design Decisions
*Are decisions explained after the final converge phase?*

| Score | Level | Description |
| :--- | :--- | :--- |
| **+0** | **Poor** | No explanation given for why a specific design was chosen for final implementation. |
| **+1** | **Sufficient** | An explanation is provided for the final design choice. |
| **+2** | **Good** | A robust explanation, **grounded in visualisation theory**, is provided for the final design choice. |
