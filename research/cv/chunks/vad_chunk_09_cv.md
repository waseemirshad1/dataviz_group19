# [agent_24] Visualization Analysis and Design — pages 401-430

## Note on Source Pages

Pages 401–430 are back matter (Bibliography, Idiom & System Examples Index, Concept Index). CV ideas below draw on the complete idiom catalogue revealed by the index (pp. 422–423), using idioms from throughout the book to suggest ways to visualize a non-traditional CV for a psychology + sales + software development background targeting a data science / ML internship at ML6 in Belgium.

---

### CV Idea: LineUp Skills Ranking (p. 246–248)

- **What it visualizes:** Multiple competencies (Python, statistics, sales persuasion, psychology, R, data visualization, ML fundamentals) ranked by relevance to the ML6 role, with individual attribute bars showing proficiency depth.
- **How it works:** Each skill is a column in a LineUp-style layout; each "item" is a skill area; bars show self-assessed proficiency; the composite score weights technical skills highest for ML6, but the weighting itself is visible — demonstrating awareness of what matters.
- **Adaptation for our context:** Replace sites with skill areas; replace biodiversity metrics with competency sub-dimensions (e.g., for Python: scripting / OOP / data manipulation / ML frameworks). The visual argument: "I know which skills matter most for your context and I have quantified my own gaps honestly."
- **Page reference:** p. 246–248

---

### CV Idea: Parallel Coordinates Career Trajectory (p. 162–166)

- **What it visualizes:** Career stages (student / sales role / software dev side projects / data science coursework) as items on a parallel coordinate plot, with axes for: technical depth, communication skill, domain knowledge, autonomy, data relevance.
- **How it works:** Each career phase is a polyline. The lines converge toward the data science / ML axis — showing that each role contributed to a different dimension of the ML internship profile. The visual argument: "My background is multi-axis, not linear, and each axis points at the same destination."
- **Adaptation for our context:** Normalize each axis 0–100; label each polyline with the phase name and duration; use color to distinguish academic vs. professional vs. project phases. Highlight the convergence zone at the "ML6 intern" endpoint.
- **Page reference:** p. 162–166

### CV Idea: Cluster Heatmap of Projects × Skills (p. 158–160)

- **What it visualizes:** A matrix of projects/experiences (rows) × skills demonstrated (columns), with color intensity showing depth of use. Hierarchical clustering groups similar projects together; dendrogram on the skill axis groups related competencies.
- **How it works:** Binary or ordinal fill (0 = not used, 1 = used, 2 = led/owned) in each cell. Clustering reveals that even non-technical experiences (sales) cluster with communication and stakeholder management skills that are also required for ML consulting. The visual argument: "My experiences are more coherent than they appear — they cluster naturally around data-driven decision-making."
- **Adaptation for our context:** Include ~8 projects/roles and ~12 skill categories. Use a diverging color scheme (gray = not used, blue gradient = depth of use). Keep the matrix small enough to read without zooming.
- **Page reference:** p. 158–160

### CV Idea: Animated Transition Before/After Profile (p. 248–249)

- **What it visualizes:** A radar/spider chart (or bar chart) showing competency profile that animates from "background entering the program" to "current state after coursework/projects." The animation makes growth visible.
- **How it works:** Two states: initial state (sales/psychology background, low technical depth) and current state (after data viz course, ML projects, software dev). Animated transition between the two using smooth morphing. The visual argument: "Look how much ground I've covered — and the trajectory is clear."
- **Adaptation for our context:** Use a simple horizontal bar chart (more perceptually accurate than radar) for the two states; animate bar growth on page load; include small annotations at the end of key bars ("completed Coursera ML specialization", "built visualization project for ecology dataset").
- **Page reference:** p. 248–249 (animated transitions), p. 150–151 (bar charts)

### CV Idea: Focus+Context Timeline with DOI Highlighting (p. 323–338)

- **What it visualizes:** A timeline of all experiences and projects (education, sales, software dev projects, data science coursework) using a fisheye or stretch-and-squish lens that expands the most recent and most relevant items while compressing older/less relevant ones.
- **How it works:** The full timeline is visible at once (context) but the last 2 years of data science work are given more visual space (focus). Degree-of-interest (DOI) is assigned by relevance to ML6 role — items with high DOI (ML projects, data viz, Python work) are larger; items with lower DOI (older sales) are compressed but still visible (showing breadth without noise).
- **Adaptation for our context:** A static version can be achieved with a non-linear x-axis (more pixels per month for recent/relevant period); a dynamic version adds hover to expand any item. The visual argument: "I have a history — but what's relevant to you gets the space it deserves."
- **Page reference:** p. 323–338 (focus+context, DOI models)

### CV Idea: Scatterplot — Skills × Relevance (p. 146–148)

- **What it visualizes:** Each skill as a dot in a 2D space: x-axis = proficiency level (self-assessed, 1–5); y-axis = relevance to ML6 role (estimated from job description, 1–5); size = years of experience; color = domain (technical / communication / domain knowledge).
- **How it works:** The upper-right quadrant (high proficiency + high relevance) shows the core value proposition. Lower-right (high relevance, lower proficiency) shows honest growth areas. Upper-left (high proficiency, niche relevance) shows transferable strengths. The visual argument: "I know where I stand and I know what matters for your role."
- **Adaptation for our context:** ~15–20 skills plotted; annotate 3–4 key skills with brief labels; use a light reference quadrant grid. Include a small bubble for "ML internship requirements" derived from the ML6 job description to show the target zone.
- **Page reference:** p. 146–148 (scatterplots)

### CV Idea: Small Multiples Project Profiles (p. 282–284)

- **What it visualizes:** Each significant project shown as a small identical chart (e.g., radar chart or bar chart of 5 dimensions: technical depth, business impact, team size, domain novelty, data complexity). All charts use the same scale, allowing rapid comparison.
- **How it works:** ~5–6 project panels in a grid. The trellis layout means the reader can scan across all projects and spot that each one covers different dimensions — demonstrating breadth. The visual argument: "My projects are complementary, not redundant — together they cover the full ML pipeline."
- **Adaptation for our context:** Use horizontal bar charts per project (5 bars each) rather than radar charts (radar has perceptual issues). Sort projects by technical depth. Include the ecology data visualization project as a recent high-complexity, high-novelty entry.
- **Page reference:** p. 282–284 (trellis / small multiples)
