# [agent_04] Cool Infographics — pages 151-200

Pages 151–178 contain by far the richest concentration of infographic CV content in this chunk. Multiple fully detailed resume examples are shown and described. Pages 179–200 shift to internal corporate infographics, with no CV-specific content.

### CV Idea: Software/Skill Icons + Proficiency Bar Chart (combined) (p.151–152)

- **What it visualizes:** Technical skills — software applications used, with proficiency level
- **How it works:** Software application icons (Illustrator, Photoshop, InDesign, Dreamweaver) are placed as coloured squares/badges to show which tools are used; a separate relative experience bar chart shows proficiency percentage for each tool. The icons serve as the legend — no text labels needed for recognized software. (Tina Chen example: icons for primary programs; Anibal Maiz Caceres example: bar chart with icons as x-axis labels)
- **Adaptation for our context:** Use recognised icons for Python, SQL, Excel, scikit-learn, Tableau, etc. alongside a bar chart showing proficiency level. This communicates the data science tech stack instantly to a technical hiring manager. For the psychology→data science pivot: include icons for both "soft" tools (Word, Salesforce) and "hard" tools (Python, R) with bars making the transition trajectory visible — soft tools taller on the left, data tools growing on the right.
- **Page reference:** p.151–152

### CV Idea: Relative Experience Bar Chart with Proficiency Level (p.152, Fig. 4-16 Anibal Maiz Caceres)

- **What it visualizes:** Software/skill proficiency expressed as a percentage of maximum possible proficiency
- **How it works:** A grouped or individual bar chart where each bar represents one tool/skill; bar height = proficiency percentage (0–100%); software icons placed at the base of each bar serve as category labels. Language proficiency shown as a pie chart with percentage labels and flag icons for each language.
- **Adaptation for our context:** Show programming languages (Python, SQL, R) and data science tools with varying bar heights, making the data science trajectory visible — newer skills at lower heights, psychology/sales skills high. Could use the pie/wheel chart for language proficiency (Dutch, English, French) using flag icons. The key insight: this design works across languages because icons replace text, which is relevant for international applications.
- **Page reference:** p.152

### CV Idea: DNA Strand Timeline for Career History (p.154, Fig. 4-17 Mino Parisi)

- **What it visualizes:** Career and education history over time, with metaphorical continuity
- **How it works:** A horizontal or vertical timeline is styled as a DNA double helix. Events (jobs, degrees, certifications) are attached to the strand at the corresponding year. The double strand allows two simultaneous tracks (e.g., formal education = top strand, work experience = bottom strand). The DNA metaphor implies professional identity is "encoded" in experience.
- **Adaptation for our context:** Top strand = formal education (Psychology degree, current data science studies); bottom strand = work experience (sales roles, software development). The strands visually intersect around the period where the pivot happens (studies begin while commercial work continues), showing the transition is happening in parallel, not sequentially. This makes the non-linear career path look intentional rather than scattered.
- **Page reference:** p.154

### CV Idea: Overlapping Skill Bubble Clusters (p.154, Fig. 4-17 Mino Parisi — "What I use most" / Jack Hagley version)

- **What it visualizes:** Skills and competencies with relative importance shown through bubble size and overlap
- **How it works:** Circles of varying sizes represent skill areas. Size = relative proficiency or importance. Overlap between circles = conceptual relationship between skills. No axis needed. (Mino Parisi: Illustrator, Photoshop, InDesign as overlapping coloured circles. Jack Hagley: Data Visualisation, Infographics, Graphic Design, Problem Solving, etc. as varying sized open circles.)
- **Adaptation for our context:** Cluster 1 (large): Data Science, Python, Machine Learning. Cluster 2 (large): Communication, Negotiation, Sales. Cluster 3 (medium): Psychology, Research Methods, Statistics. Cluster 4 (small, overlapping with all): Creativity, Analytical Mindset. The overlap between Cluster 1 and Cluster 2 (data science + communication) is the unique selling point — few data scientists have strong commercial communication skills.
- **Page reference:** p.154, p.162 (Jack Hagley version)

### CV Idea: Four Donut Charts — Skills Proficiency by Domain (p.154–155, Fig. 4-17 Mino Parisi)

- **What it visualizes:** Relative proficiency allocation across tools within each work domain (Print, Web/UI, UX Design, Product/Packaging)
- **How it works:** One donut chart per domain. Each donut segment = one tool/skill; arc length = proportion of that tool's contribution within the domain. A shared colour legend maps tool identity to segment colour. This shows not just "I know these tools" but "which tools I emphasize in which context."
- **Adaptation for our context:** One donut per role context: (1) Sales/Commercial roles — negotiation, CRM, presentation; (2) Software development — coding, system design, debugging; (3) Data science studies — Python, ML, statistics, visualization; (4) Psychology/Research — research methods, analysis, writing. Each donut shows the skill mix relevant to that context, telling the story that the candidate has diverse but structured competency profiles, not just a list of skills.
- **Page reference:** p.154–155

### CV Idea: Horizontal Timeline with Event Markers — Vanessa Wilson Style (p.157–158, Fig. 4-19)

- **What it visualizes:** Career timeline showing overlapping work, education, and volunteer/side-project tracks simultaneously
- **How it works:** Three parallel curved lines run vertically (or horizontally) down the page, colour-coded by track type (work experience / education / personal projects). Each event is a labelled node on the appropriate line. Where multiple events overlap in time, all lines are visible simultaneously. Skill bars are placed in a side panel.
- **Adaptation for our context:** Three tracks: (1) Work experience (sales jobs, software development); (2) Education (Psychology degree, current data science course); (3) Self-directed projects/certifications (e.g., Kaggle competitions, personal data projects). The overlap zone — where the data science course runs alongside commercial work — visually demonstrates that the transition is active and committed, not hypothetical.
- **Page reference:** p.157–158

### CV Idea: Jack Hagley Style — "What I do / How I look at the world" Multi-Panel (p.162, Fig. 4-22)

- **What it visualizes:** Personality type, time allocation, skill proficiency, career history, and interests — all on one page with minimal text
- **How it works:** Multiple small panels on a single black-and-white page, each answering a specific question about the person: (1) Bubble cluster = skills and relative importance; (2) MBTI or personality trait sliders = "how I look at the world"; (3) Radial time-allocation chart = "what I do with my time" (pie chart of daily activities); (4) Timeline strip = career and education history; (5) Icon row = hobbies/interests; (6) Miscellaneous numbers (age, fun facts). Deliberately minimal use of color — entirely printable.
- **Adaptation for our context:** Panel 1: Skill bubbles (Python, sales, psychology, creativity). Panel 2: Personality sliders (analytical/creative; introvert/extrovert — psychology background makes this credible and interesting). Panel 3: Time allocation wheel showing current day split between studying, working, projects. Panel 4: Multi-track timeline of degrees and jobs. Panel 5: Icons for interests (data, psychology, languages, music). This format is ideal for AI/tech companies that value personality alongside technical skills. The black-and-white constraint also means it prints perfectly on any office printer.
- **Page reference:** p.162

### CV Idea: Dual Concentric Ring Skill Glyph (proficiency vs. frequency) (p.173, Fig. 4-28 cvgram.me)

- **What it visualizes:** For each skill: both mastery level (how good) and usage frequency (how often used)
- **How it works:** Each skill is shown as two concentric donuts. Outer ring arc = expertise level (filled clockwise from 0 to 100%). Inner ring arc = frequency of use. A star icon marks top skills. Labels below each glyph indicate level category (Pro/Advanced/Intermediate/Beginner) and frequency category (Always/Usually/Regular/Sometimes).
- **Adaptation for our context:** Apply to data science skills: Python (outer: advanced, inner: daily), SQL (outer: intermediate, inner: regular), Statistics (outer: advanced, inner: always), Machine Learning (outer: intermediate, inner: regular), Sales CRM tools (outer: expert, inner: now rarely — showing transition away from sales). The divergence between expertise and current frequency is honest and interesting — it signals which skills are being grown vs. which are legacy skills.
- **Page reference:** p.173

### CV Idea: LinkedIn Network Map as Professional Reach Visualisation (p.175–176, Fig. 4-30)

- **What it visualizes:** Professional network breadth and industry diversity; shows how connected and engaged the candidate is in their field
- **How it works:** LinkedIn InMaps (or similar) generates a network graph of all professional connections, with nodes colour-clustered by industry. The resulting image shows the candidate at the centre, with dense clusters of connections in their primary industries and bridge connections between clusters. This is included as a panel in the infographic resume.
- **Adaptation for our context:** For a psychology→data science pivot candidate, the network map would likely show a cluster in commercial/sales, a cluster in tech/software, and a smaller but growing cluster in data/AI. The bridge nodes (people who span clusters) are the most interesting — they signal the candidate is actively building cross-domain connections. This is a qualitative signal of community engagement, not a quantitative skill claim, but it adds authenticity.
- **Page reference:** p.175–176

### CV Idea: Standalone Infographic + Embedded Text Hybrid (p.157–158, general principle)

- **What it visualizes:** All CV sections, designed so that data visuals are embedded adjacent to the corresponding text descriptions — minimising eye movement and making the visual context immediately available
- **How it works:** Rather than creating a separate visual resume, embed small visualisations directly within a standard document layout: a small timeline next to the work experience section, a skill bubble chart next to the skills section, a donut chart next to the education section. The full text is preserved for job application systems; the visuals add a layer that a hiring manager reading the document will immediately notice.
- **Adaptation for our context:** For AI/data science applications: the data visualisations embedded in the CV themselves demonstrate data visualization competence — the medium is the message. The psychology background gives an unusual angle: a section titled "How I understand people" with a mini radar of soft skills, adjacent to "How I work with data" with a mini proficiency chart.
- **Page reference:** p.157–158

### CV Idea: Re.vu / Vizualize.me Style — Multiple Chart Types per Section (p.166, 171, Figs. 4-24, 4-26)

- **What it visualizes:** Full resume sections — skills, work history, education, interests, stats — each using a different visual type appropriate to that data
- **How it works:** The re.vu and vizualize.me platforms demonstrate that each CV section warrants its own chart type: timeline for work history, bar or donut for skills, area chart for "interests over time", icon grid for personal stats (years of experience, number of connections, etc.). The overall page uses consistent color branding but varies chart type by section purpose.
- **Adaptation for our context:** Work history → horizontal timeline with coloured bars per employer. Skills → opposing bar chart with left = technical skills, right = soft skills (the trade-off between hard/soft is itself a story). Education → timeline. Growth narrative → area chart showing self-assessed data science skill level over the past 3 years, overlaid on a line showing commercial experience declining. Personal stats → icon array: "X hours of Python practice", "Y Kaggle competitions", "Z sales value managed".
- **Page reference:** p.166, p.171
