### CV Idea: Fractal Career Tree (inspired by p.271–274)

- **What it visualizes:** Career trajectory, education, and skills — structured as a growing tree where branches represent different domains and leaves represent skills, achievements, or roles.
- **How it works:** A central trunk represents the core identity (the person). Three main branches grow outward: Branch 1 = Education (Psychology degree, data science courses), Branch 2 = Work Experience (sales/commercial roles, software development), Branch 3 = Current Direction (AI/data science pivot). Each branch sprouts leaves — each leaf = one specific skill, tool, or achievement. Leaf color hue = domain (soft skills = warm tones, technical skills = cool tones, creative/analytical = neutral). Leaf size = proficiency or time invested. The tree is denser on the "current direction" branch, showing where growth is concentrated now.
- **Adaptation for our context:** The trunk clearly shows the "pivot" story — the tree grew from a Psychology root, expanded through commercial branches, and is now sending new growth in the direction of data science/AI. The shift is visible as a directional lean in the branch structure: older branches (left) are established; the right-most branch (data science) is actively sprouting. A small annotation near the data science branch: "currently growing."
- **Page reference:** p.271–274

### CV Idea: Beads-on-a-String Career Timeline (inspired by p.282–295)

- **What it visualizes:** Work experience and education timeline, with each role as a bead and skill profile as a mini-glyph inside each bead.
- **How it works:** A winding string represents time (left = past, right = present). Each major role, degree, or project is a circle/bead on the string. Inside each bead: a small radial glyph (flower or radar) with petals encoding key competencies active during that period (e.g., communication, analytical, technical, creative, commercial). The string curves upward toward the present, suggesting upward trajectory. Bead size = duration of the role.
- **Adaptation for our context:** The early beads (psychology, sales) have large soft-skill petals and small technical petals. The middle beads (software development) show technical petals growing. The rightmost bead (current/AI study) shows both technical and analytical petals large — demonstrating convergence. The overall picture: someone who has always had the soft skills and is now building the technical side. The string itself communicates narrative continuity — this is not a career change, it is a career growth story.
- **Page reference:** p.282–295

### CV Idea: The Tooltip Resume — Static Card with Reveal Depth (inspired by p.288, p.274)

- **What it visualizes:** Summary-level CV as a clean, minimal card; deeper hover/reveal layers show full detail per section — skills, experience, growth trajectory.
- **How it works:** The visible layer is a minimal business-card-style layout: name, headline ("Psychology → Data Science"), and icons for 5 core competencies. Each icon, when hovered (in a digital PDF or web version), reveals a "tooltip" panel that functions like the elaborate hover tooltip in the book: a small trend line (showing growth in that skill over time), a word-tag cloud of specific tools/experiences, and a one-line annotation about the most notable moment.
- **Adaptation for our context:** For "Analytical mindset": tooltip shows a trend line of increasingly technical coursework over time + tag cloud: "R, Python, data visualization, ML6 application." For "Social intelligence": tooltip shows "psychology thesis → sales → client management → team collaboration in software development." The top-level card stays clean and bold; the depth is there for recruiters who engage. This format suits a digital-first application (ML6, Belgium) where the resume may be viewed on screen rather than printed.
- **Page reference:** p.288, p.274

### CV Idea: Language Similarity Network Adapted as Skill Adjacency Map (inspired by p.289–296)

- **What it visualizes:** How skills, domains, and experiences are interconnected — presenting the applicant as someone whose competencies reinforce each other rather than exist in silos.
- **How it works:** Each major skill or domain is a circle node (e.g., Psychology, Data Analysis, Sales & Negotiation, Software Development, Communication, Creativity, Machine Learning). Lines connect nodes that are naturally adjacent or mutually reinforcing — the line carries a short word label explaining the connection (e.g., "user research" links Psychology to Data Analysis; "client modeling" links Sales to Data Analysis). Multiple connections between two nodes use progressively more curved lines. Nodes are color-coded by domain type (human/soft = warm, technical = cool, creative = neutral). Node size = strength/depth of competency.
- **Adaptation for our context:** The network visually argues that the Psychology-to-Data-Science path is not a gap but a web — every prior domain connects to the target domain. The recruiter at ML6 sees that Data Analysis sits at the center of the network, with connections coming from multiple directions (psychology, software development, creativity, commercial experience). This counters the risk of appearing "not technical enough" by showing that the technical node is densely connected.
- **Page reference:** p.289–296

### CV Idea: Minimalist Word Ring — Core Identity at a Glance (inspired by p.285–295)

- **What it visualizes:** Top skills and character traits, arranged in a radial arc / tree-ring layout where the most important appear at the center and less prominent ones radiate outward.
- **How it works:** Three concentric ring sets (like the tree ring visual): inner ring = identity traits (empathetic, analytical, creative), middle ring = domain skills (data visualization, Python/R, communication, negotiation), outer ring = tools and specifics (pandas, ggplot2, D3.js, Excel). Text runs along the arc path. Each ring is a different color family. The English (primary) term is in bold black; any alternative/synonym is smaller and grey.
- **Adaptation for our context:** The innermost ring communicates character before competency — starting with "who I am" (analytical, social, creative) before "what I can do." This matches the psychology background's emphasis on human traits. The outermost ring shows the technical specifics that are currently being developed. Reading from center outward tells the story: strong character foundation → domain skills → growing technical toolkit. This layout is compact enough for a half-page section of a print CV or a full-page visual resume cover sheet.
- **Page reference:** p.285–295
